# Privacy Policy

Briefly is a news reader demo app.

## Data Stored On Device

The app may store:

- Bookmarked articles
- Recent search terms
- Theme and font-size preferences
- Region and language preferences

This data is stored locally on the user's device.

## Data Sent To Third Parties

The app sends news requests to GNews to fetch headlines and search results. Requests may include:

- Search query text
- Selected news category
- Language and country parameters

Briefly does not sell user data and does not include advertising or analytics SDKs.

## API Keys

The GNews API key is a developer credential. It should not be treated as user data and should not be committed to source control.

For production web deployments, use a backend proxy so the API key is not exposed in browser code.

## Contact

For privacy or security concerns, contact the project owner.
